# CodeNest Platform Documentation

## Overview
CodeNest is a modern developer social platform designed to help software engineers build public engineering reputation and receive honest, bias-free code reviews.

## Dual Surfaces

1. **Nest Feed (Public Identity Surface)**:
   - Developers share public technical posts, code snippets, engineering insights, and tech discussions under their real profile.
   - Features: Public developer feed, Real-Time 1-to-1 Live Chat for mutual connections (message edit/delete, thread deletion, seen status receipts, sender toast notifications), AI Personal Learning Roadmap Generator, Community hubs, Follow/Unfollow, Connection Requests, and Notifications.

2. **Nest Shadow (Anonymous Code Review Surface)**:
   - Developers submit code snippets anonymously to receive constructive, bias-free reviews from peers without gender, age, title, or background bias.
   - Features: Anonymous queue, Custom Anonymous Communities (`+ Create Anon Community`), Anonymous code review submissions with language filters (C++, Python, JS, Go, Rust, Java, etc.), Structured review forms (What Went Well, What Could Be Improved, Recommended Resources, Helpfulness Rating), Anonymous reputation score, and My Submissions / My Reviews tracking.

## Key Features & AI Integrations
- **Real-Time Live Messaging**: 1-to-1 live chat restricted to mutual connections with socket-driven real-time updates.
- **Automatic System Theme Engine**: Auto-detects OS color scheme (`prefers-color-scheme: dark`) with instant pre-render script preventing screen flicker on startup.
- **AI Personal Learning Roadmap Generator**: Generates customized study roadmaps based on experience level and tech stack.
- **Smart Developer Recommendation Engine**: Multi-factor weighted scoring algorithm for developer connections based on activity, technology similarity, mutual connections, and freshness.
- **CodeNest Guide & Shadow Mentor**: Dual AI Assistants providing RAG-backed platform help, computer science concepts, DSA guidance, code review etiquette, and creator knowledge.
